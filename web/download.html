Get the app

4 Horseman Security on your phone

Officers and supervisors sign in with your company code and their PIN. The app works on Android phones and iPhones.

Android

Download for Android
  1. Open the downloaded file on your phone.
  2. If Android asks, allow your browser to install apps.
  3. Tap Install, then open 4 Horseman Security.
Install on Android
  1. Tap Install on Android, using Chrome.
  2. Tap Install when Chrome offers it, or open the ⋮ menu and choose Install app.
  3. Open 4 Horseman Security from your home screen.

iPhone

Install on iPhone
  1. Tap Install on iPhone, using Safari.
  2. Tap the Share button, then Add to Home Screen.
  3. Open 4 Horseman Security from your home screen. It runs full screen like any other app.
